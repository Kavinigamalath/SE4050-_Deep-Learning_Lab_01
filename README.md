# SE4050 – Deep Learning | Lab Sheet 1

Introduction to Python libraries for Deep Learning (NumPy, Matplotlib, Pandas, Seaborn).

## Notebooks

| File | Description |
|------|-------------|
| `task1_numpy_matplotlib_seaborn.ipynb` | Task 1 – NumPy exponential arrays, distribution histograms, 3D surface plot, Pokémon Pearson/Spearman heatmaps |
| `task2_au_nanoparticle.ipynb` | Task 2 – Au nanoparticle dataset filtering, stats, histograms, pairplot, PairGrid |

## Datasets

- **Pokémon:** `Pokemon.csv` / `data/Pokemon.csv` (bundled; same file as the course Seaborn tutorial)
- **Au nanoparticles:** download `Au_nanoparticle_dataset.csv` into `data/` from [this Google Drive folder](https://drive.google.com/drive/folders/1_6-GpmILQB4-8rMf5oW604pP1Nx54dYx?usp=sharing)

## How to run

### Google Colab (recommended by the lab)
1. Upload each notebook to Drive → open with Colab.
2. For Task 2, upload `Au_nanoparticle_dataset.csv` into the Colab session (Files panel).

### Local
```bash
pip install -r requirements.txt
jupyter notebook
```
